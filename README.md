# ОСНОВА · админка — демонстрационный прототип

Рабочее место продакта ОСНОВЫ: данные, обращения и сообщения сотрудникам учреждений.

**Открыть:** https://mitina-code.github.io/osnova_admin_demo/

Рабочее место цензора — в отдельной демонстрации:
https://mitina-code.github.io/osnova-demo/

## Что умеет

**Загрузка данных.** Выгрузка из сервисов ЗТ в базу материалов, с которой работают
цензоры. Файл разбирается построчно: проверяются колонки, значения риска, направления
и канала, обязательные поля. Строки с ошибками пропускаются с объяснением причины,
годные загружаются — файл целиком не отклоняется.

**Обращения.** Вопросы от заключённых и их родственников. Готовые тексты ответов,
отметка срока, фиксация ответа в деле. Норматив ответа — 3 дня.

**Канал ОСНОВЫ.** Сообщения сотрудникам учреждений: выбор получателей, закрепление
важного наверху, подтверждение перед отправкой со списком тех, кто увидит.

## Формат файла для загрузки

Таблица Excel, сохранённая как **CSV UTF-8**, разделитель — точка с запятой.
Первая строка — заголовки:

```
id;дата;направление;канал;язык;отправитель;получатель;риск;резюме;основание;текст
```

| Колонка | Допустимые значения |
|---|---|
| `риск` | зелёный · оранжевый · красный |
| `направление` | входящее · исходящее |
| `канал` | письмо · голосовое · видео |
| обязательные | id, дата, отправитель, получатель, риск |

Готовый пример — `example.csv` в этом репозитории. В нём четыре правильные строки
и одна с ошибками: так видно, как работает проверка.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Страница-вход с подсказками |
| `admin.html` | Сама админка |
| `example.csv` | Пример файла для загрузки |
| `data-reference.js` | Обращения, канал, нормативные акты |
| `data-shift-peak.js` | Набор материалов: 500 за смену |

Обычная веб-страница: открывается двойным кликом, серверов и установки не требует.

## Данные

Все имена, обращения, сообщения и материалы **вымышленные**, сгенерированы для
демонстрации. Совпадения с реальными людьми случайны. Персональных данных здесь нет.

## Границы прототипа

- загрузка разбирает файл по-настоящему, но в базу ничего не пишет;
- формат `.xlsx` пока не читается, только CSV;
- ответы и сообщения никуда не уходят;
- входа по логину нет;
- прототип ничего не сохраняет между открытиями.
